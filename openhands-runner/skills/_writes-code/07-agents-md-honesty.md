# AGENTS.md — keep it honest

Update AGENTS.md only when the change you shipped makes it wrong: correct the
stale statement (a command, a convention, a layout fact) as part of the change.
NEVER create AGENTS.md if the repo doesn't have one — authoring it from scratch
is onboarding work, not part of a feature or fix task. Repeatable learnings go
in `.agent/skills/<topic>.md`, not AGENTS.md.
